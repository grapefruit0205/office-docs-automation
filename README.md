# 실무 서류 자동 생성 세트 (구글시트 + Apps Script)

점검 기록 **5,040행**에서 요약표 · 점검대장(`.xlsx`) · 작업계획서 · 점검결과보고서 **20부**를 자동으로 만드는 예제입니다.

> ⚠️ **데이터는 전부 합성(가상)입니다.** 실제 회사 자료·설비 태그·인명을 쓰지 않았습니다. 예제 회사는 `(주)가상케미칼` 입니다.
> 실행 환경: 구글 계정(무료) + Apps Script. 별도 서버·유료 라이선스 없음.

---

## 1. 무엇을 하는가

현장에서 쓰는 서류 3종(대장 · 계획서 · 결과보고서)을 **손으로 만들지 않고 데이터에서 만들어 냅니다.**

| 구분 | 내용 |
|---|---|
| 입력 | 점검기록 5,040행(설비 20대 × 28일 × 9항목) · 설비마스터 20대 |
| ① | 요약표 2종 — 설비별/항목별 이상 건수·심각도·미조치 (COUNTIFS 수식) |
| ② | 점검대장 `.xlsx` — 제목·결재란·조건부 서식·데이터 검증이 붙은 인쇄용 대장 (엑셀에서 열림) |
| ③ | 작업계획서 20부 — PDF + DOCX + 구글독스 |
| ④ | 점검결과보고서 20부 — 설비별 통계·항목별 이상·이상 상세·조치 현황·종합 의견 |
| ⑤ | 합본 PDF · 발행이력 · 자동/수작업 소요 시간 로그 |

**핵심**: 대장의 수식은 엑셀에서도 그대로 계산되는 것만 씁니다.
`COUNTIFS` `IF` `TEXT` `MAXIFS` `XLOOKUP` — `QUERY` `FILTER` `ARRAYFORMULA` 는 엑셀에 없으므로 쓰지 않았습니다.

## 2. 시트 구성 (9탭 + 선택 1탭)

| 탭 | 내용 | 채우는 방법 |
|---|---|---|
| `안내` | 사용 순서·구성 설명 | 설치 시 코드가 작성 |
| `설비마스터` | 설비 20대 기준 정보 | 데이터 |
| `점검기록` | 점검 1건당 1행 5,040행 | 데이터 (설비명·구역·담당자는 수식) |
| `작업계획` | 설비별 이상 건수 상위부터 작업계획 20건 | 데이터 |
| `설정` | 회사명·기간·한 번에 만들 문서 수 등 16개 | 설치 시 기본값 |
| `요약_설비별` | 설비×항목 이상 건수·점검횟수·이상률 | `COUNTIFS` 수식 20행 |
| `요약_항목별` | 항목별 이상·심각도·미조치·최근 발생일 | `COUNTIFS`/`MAXIFS` 수식 9행 |
| `발행이력` | 만든 문서의 링크·소요 초·상태·오류 | 문서 생성 시 자동 |
| `측정로그` | 자동/수작업 소요 시간 비교 | 실행 시 자동 |
| `피벗` (선택) | Sheets API 고급 서비스가 있으면 네이티브 피벗 | 미리보기용 |

`점검기록`의 **설비명·구역·담당자는 값이 아니라 수식**입니다. 설비마스터를 고치면 5,040행이 따라 바뀝니다.
(엑셀 호환을 위해 `ARRAYFORMULA` 대신 행마다 `XLOOKUP` 을 넣었습니다 — `설정` 탭의 `조회함수` 값을 `INDEXMATCH` 로 바꾸면 `INDEX/MATCH` 로 생성됩니다.)

**계산 비용**: 수식 범위를 전체 열(`$A:$A` = 100만 행) 대신 실제 데이터 범위(`$A$2:$A$21`, `$2:$5041`)로 잡았습니다.
5,040행 × 3열 = 15,120개 수식에서 이 차이가 시트 반응 속도를 가릅니다.
점검기록에 행을 **추가**했다면 메뉴 `요약 다시 계산` 을 한 번 실행해 범위를 다시 잡아 주세요.

## 3. 문서 2종

템플릿 문서를 미리 만들지 않습니다. **구글독스를 코드로 그려서** 서식을 통제합니다(자리표시자 불일치 문제가 없습니다).

- **작업계획서** (A4 1장): 제목·결재란(담당/검토/승인) → 기본 정보 → 작업 내용 → 위험요인·안전조치(빨강) → 필요 자재·공구 → 확인(서명란)
- **점검결과보고서** (A4 1~2장): 제목·결재란 → 설비 정보 → 점검 요약 카드(점검 횟수/이상 건수/이상률/미조치) → 항목별 이상 건수(0건은 회색, 미조치는 빨강) → 이상 상세(심각도 순, 최대 15건 + `외 N건`) → 조치 현황 → 종합 의견(자동 문장) → 확인(서명란)
- 저장: 드라이브 `서류자동화_포트폴리오/출력` 에 **PDF·DOCX**, 원본 구글독스는 `구글독스` 폴더에 보관(재편집·검증용)
- 파일명: `WP-2026-0001_PU-03_작업계획서.pdf` · `IR-2026-0003_AC-01_점검결과보고서.pdf`

## 4. 실행 순서

| 순서 | 실행 | 기대 결과 |
|---|---|---|
| 1 | `설치_전체` | 탭 9개·설정 16개·드라이브 폴더 생성, 수식·서식 적용. **두 번 돌려도 데이터가 지워지지 않습니다** |
| 2 | `설치_샘플데이터` | 합성 데이터 5,040행 + 작업계획 20건 생성 |
| 3 | `대장내보내기` (메뉴) | `출력` 폴더에 `점검대장_YYYY-MM.xlsx` |
| 4 | `양식_일괄생성('작업계획서')` ×3회 | 8부씩 → 20부 완성 |
| 5 | `양식_일괄생성('점검결과보고서')` ×3회 | 8부씩 → 20부 완성 |
| 6 | `합본PDF('점검결과보고서')` | 20부를 이어 붙인 합본 PDF 1개 |
| 7 | `검증_문서대조('점검결과보고서')` | 원본 데이터와 문서 본문을 문자열로 대조 → `누락 0건` |

무료 계정은 **1회 실행 6분 제한**이 있어 문서를 8부씩 나눠 만듭니다(`설정` 탭 `문서한번에`).
시간이 다 되어 멈추면 그때까지 만든 문서는 발행이력에 남고, 다시 실행하면 **남은 것만** 만듭니다.

시트 메뉴 `[서류자동화]` 에서도 같은 기능을 실행할 수 있습니다(설치 후 시트를 새로 열면 메뉴가 생깁니다).

## 5. 검증 (눈으로 읽지 않고 기계로 대조)

```
검증_문서대조('점검결과보고서')
→ 대조 20부 / 320항목 중 누락 0건
```

원본 행의 모든 값(설비태그·설비명·구역·담당자·작업일…)이 문서 본문에 실제로 들어 있는지 문자열로 확인합니다.
누락이 있으면 `발행이력` 상태가 `오류` 로 바뀌고, 다시 `양식_일괄생성` 을 돌리면 그 건만 재생성됩니다.

```
서류자동화_포트폴리오/
```

## 7. 코드 구조

| 파일 | 역할 |
|---|---|
| `Code.js` | 공통 도구 · 대장 수식/서식 · 요약(COUNTIFS) · xlsx 내보내기 · 발행이력 |
| `양식.js` | 문서 서식 도구 · 작업계획서/점검결과보고서 작성 · 저장 · 합본 · 검증 |
| `설치.js` | 탭·설정·폴더 설치 · 합성 데이터 생성 · 메뉴 · 측정 |
| `설치_한번에.js` | 위 3개를 합친 파일 — 편집기에 붙여넣기용(설치 경로가 쉬운 방법) |

## 8. 재현 방법

### 방법 A — 붙여넣기 (가장 빠름)
1. 구글시트를 새로 만들고 이름을 `서류자동화_포트폴리오` 로 변경
2. **확장 프로그램 → Apps Script** → `Code.gs` 내용을 지우고 `설치_한번에.js` 전체를 붙여넣기
3. 프로젝트 설정 → "appsscript.json 매니페스트 표시" 체크 → `appsscript.json` 내용으로 교체
4. 저장(Ctrl+S) → 함수 `설치_전체` 실행 → 권한 허용(본인 스크립트이므로 **고급 → 프로젝트로 이동** )
5. 시트로 돌아가 F5 → 메뉴 `[서류자동화]` 확인

### 방법 B — clasp (코드 동기화)
```bash
npm install -g @google/clasp
```

```bash
clasp login
```

```bash
clasp create --type sheets --title "서류자동화_포트폴리오" --rootDir .
```

```bash
clasp push --force
```

> `clasp` 는 `설치_한번에.js` 를 올리지 않습니다(`.claspignore`). 같은 함수가 두 번 선언되면 실행이 깨지기 때문입니다.
> Apps Script API 사용 설정이 필요합니다: <https://script.google.com/home/usersettings>

## 9. 한계와 다음 단계

- 피벗 탭은 **선택**입니다. Sheets API 고급 서비스가 없으면 요약 탭으로 대체하고 로그에 남깁니다(설계상 의도).
- 엑셀 변환은 `getAs` 가 계정 상태에 따라 막히는 경우가 있어 **다운로드 URL 경로까지 자동으로 시도**합니다(`_내보내기()`). 둘 다 안 되면 구글시트 사본을 `출력` 폴더에 남기고 로그에 `[대체]` 로 남깁니다.
- `.xlsx` 로 내보낼 때 색 눈금·일부 조건부 서식은 단순 서식으로 바뀔 수 있습니다. 그래서 `요약_설비별`·`요약_항목별` 을 **항상 본체**로 둡니다.
- 6분 제한 때문에 문서는 8부씩 나눠 만듭니다. 100부 단위라면 트리거로 시간대를 나눠 돌리는 편이 낫습니다.
- 실제 업무에 적용할 때는 ① 설비마스터·기준값을 우리 회사 기준으로 바꾸고 ② 개인정보가 들어가는 열을 빼고 ③ 발행이력 보관 기간을 정하는 순서를 권합니다.
