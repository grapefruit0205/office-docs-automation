# 설치 가이드 — 구글에서 처음부터 세팅하기

> 이 문서는 ① 시트를 새로 만들지 않고 **이미 만들어진 시트**를 쓰는 경우를 포함합니다.
> 저장소 코드를 올리는 방법은 두 가지: **붙여넣기(빠름)** 또는 **clasp(자동 동기화)**.

## 0. 준비

- 구글 계정 1개 (무료)
- 드라이브 루트에 폴더를 미리 만들 필요 없음 — `설치_전체` 가 `서류자동화_포트폴리오` 폴더와 그 아래 `출력`·`구글독스` 를 자동으로 만듭니다.

## 1. 붙여넣기로 올리기 (권장)

1. 새 구글시트를 만들고 파일 이름을 `서류자동화_포트폴리오` 로 변경
2. 시트에서 **확장 프로그램 → Apps Script**
3. 왼쪽 `Code.gs` 선택 → 내용 전체 지우기 → `설치_한번에.js` 내용을 전체 붙여넣기 → 저장(Ctrl+S)
4. 왼쪽 **프로젝트 설정(⚙)** → "`appsscript.json` 매니페스트 파일 표시" 체크
5. 편집기로 돌아와 `appsscript.json` 을 저장소의 같은 파일 내용으로 교체 → 저장
6. 함수 선택 목록에서 `설치_전체` 선택 → **실행**
   - 권한 화면이 나오면 **권한 검토 → 계정 선택 → 고급 → (안전하지 않음) 프로젝트로 이동 → 허용**
   - 본인이 만든 스크립트라 정상적인 경고입니다
7. 시트로 돌아가 **F5(새로고침)** → 상단에 `[서류자동화]` 메뉴가 생깁니다

> `설치_한번에.js` 는 `Code.js` + `양식.js` + `설치.js` 를 합친 파일입니다. 한 번만 붙여넣으면 됩니다.

## 2. clasp 로 올리기 (선택)

```bash
npm install -g @google/clasp
```

```bash
clasp login
```

```bash
clasp create --type sheets --title "서류자동화_포트폴리오" --rootDir .
```

```bash
clasp push --force
```

- Apps Script API 사용 설정이 필요합니다: <https://script.google.com/home/usersettings>
- `clasp` 는 `Code.js` / `양식.js` / `설치.js` / `appsscript.json` 만 올립니다(`.claspignore`).
  **`설치_한번에.js` 는 올리지 마세요** — 같은 함수가 두 벌 선언되어 실행이 깨집니다.
- 코드를 고치면 `clasp push --force` 후 **시트에서 F5 → 함수 실행**까지 해야 반영됩니다(clasp는 코드만 올립니다).

## 3. 설치 순서

| 순서 | 실행 | 확인할 로그 |
|---|---|---|
| 1 | `설치_전체` | `탭 9개 … ` / `설정 0개 중 16개 채움` / `드라이브 폴더: 서류자동화_포트폴리오` |
| 2 | `설치_샘플데이터` | `가상 설비 20대 등록` / `가상 점검기록 5040행 생성 (YYYY-MM-DD ~ YYYY-MM-DD)` / `이상 판정 NNN건` / `작업계획 20건 생성` |
| 3 | `설치_확인` | 12항목 진단 — 전부 `○` 이고 마지막 줄이 `=== 결과: 정상 12 / 문제 0 ===` |
| 4 | 메뉴 **[서류자동화] → 점검대장(.xlsx) 내보내기** | `xlsx 저장: https://drive.google.com/...` |
| 5 | 메뉴 **작업계획서 일괄 생성(8부)** ×3회 | `결과: 성공 8건 / 실패 0건` → 마지막 회 `성공 4건` |
| 6 | 메뉴 **점검결과보고서 일괄 생성(8부)** ×3회 | 〃 |
| 7 | 메뉴 **합본 PDF 만들기** | `합본 PDF: 20건 / ...pdf` |
| 8 | 메뉴 **발행 문서 검증** | `대조 20부 / 320항목 중 누락 0건` |

> 4~8번은 시트 메뉴에서 실행합니다. 편집기에서 직접 실행해도 되지만, 메뉴 쪽이 결과를 대화상자로 보여줘 편합니다.

## 4. 문서를 다시 만들고 싶을 때

| 하고 싶은 것 | 실행 |
|---|---|
| 이미 만든 20부를 지우고 처음부터 | `초기화_출력폴더` (출력 폴더 파일 삭제 + 발행이력 초기화) |
| 잘못 만든 1건만 다시 | `발행이력` 탭에서 그 줄의 `상태` 를 `오류` 로 바꾼 뒤 `양식_일괄생성` |
| 서식만 바꿔서 다시 | `양식.js` 의 `보고서양식` 객체(색·여백·최대상세행) 수정 → clasp push → 다시 생성 |

## 5. 수작업 소요 시간 재기 (전후 비교용)

1. `측정_수작업시작` 실행 → 시각 기록
2. 엑셀·한글로 같은 문서 1부를 실제로 만들어 보기 (서식 포함)
3. `측정_수작업종료` 실행 → 만든 건수 입력
4. `측정로그` 탭에서 자동/수작업 행을 나란히 비교

> 자동 실행 시간은 문서를 만들 때마다 `측정로그` 에 자동 기록됩니다.

## 6. 주의사항

- **회사 자료 사용 금지**: 실제 점검표·설비 태그·도면·인명·사진을 쓰지 않습니다. 전부 합성 데이터입니다.
- 시트 공유는 **"링크가 있는 모든 사용자 → 뷰어"** 만. 편집 권한 공개는 금지입니다.
- 무료 계정 할당량: **1회 실행 6분**, 트리거 90분/일, 드라이브 15GB. 그래서 문서를 8부씩 나눠 만듭니다.
- 시간대가 9시간 어긋나면: 시트 **파일 → 설정 → 시간대 (GMT+09:00) 서울**, 그리고 `appsscript.json` 의 `timeZone` 을 확인하세요.
- `피벗` 탭은 Sheets API 고급 서비스가 있을 때만 만들어집니다. 없으면 로그에 `[건너뜀]` 이 남고 요약 탭이 본체 역할을 합니다.
  만들고 싶다면 편집기 왼쪽 **서비스 + → Sheets API 추가** 후 `설치_피벗` 을 실행하세요.

## 7. 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 뭔가 안 될 때 (가장 먼저) | 편집기에서 `설치_확인` 실행 → `×` 항목을 그대로 복사해 전달. 12항목을 스스로 검사해 원인을 짚어 줍니다 |
| 메뉴 `[서류자동화]` 가 안 보임 | 시트 F5 새로고침. 그래도 없으면 `onOpen` 을 편집기에서 한 번 실행 |
| `탭을 찾을 수 없습니다: 설정` | `설치_전체` 를 먼저 실행 |
| 실행 첫 줄에 `ReferenceError: SH is not defined` | 예전 코드입니다. `clasp push --force` 로 최신 코드를 올린 뒤 다시 실행하세요(파일 실행 순서 문제를 수정한 버전) |
| 문서 생성이 중간에 멈춤 | 정상 동작입니다(6분 제한). `양식_일괄생성` 을 다시 실행하면 남은 것만 만듭니다 |
| `발행이력` 에 `오류` 가 생김 | 오류 열의 내용 확인 → 원인 수정 후 다시 생성 |
| 내보낸 xlsx 에 `#REF!` | `요약` 탭에 수식이 남아 있을 때 생깁니다. `Code.js` 의 `대장내보내기` 는 값을 굳힌 뒤 내보내므로, 최신 코드인지 확인하세요 |
